# Code of Conduct

## Our pledge

We pledge to make participation in this project a harassment-free experience for everyone,
regardless of experience level, background, or identity.

## Standards

Examples of behavior that helps:

- Being respectful of differing viewpoints.
- Giving and gracefully accepting constructive feedback.
- Focusing on what's best for the project.

Examples of unacceptable behavior:

- Harassment, insults, or derogatory comments.
- Publishing others' private information without consent.
- Any conduct that would be inappropriate in a professional setting.

## Enforcement

Maintainers are responsible for clarifying standards and may remove, edit, or reject
contributions that violate this code. Report issues by opening a confidential issue or
contacting the maintainer.

This Code of Conduct is adapted from the [Contributor Covenant](https://www.contributor-covenant.org/),
version 2.1.
